## 必须保留的区别

图像压缩和码率分配使用**libx264原有机制**，本项目没有另写码率控制算法。
本项目负责参数选择、Sony封装/时序调整、SD编录和验证。

软件能解码、原厂库能读取、机身能列出、机身能播放是不同证据。
C6520/C6521修正后曾确认“能列出”；本次再次修复后，其数据库记录仍在且已补全。
C0010的“正确播放”反馈发生在本次修复之前。修复后的界面列出、播放，
以及各阶段未单独报告的完整时长/音频/跳转不能由磁盘记录代替。

`docs/experiments/`中的早期字段表保留研究历史，不是当前写卡规范。
记录起点、UMID、时间和校验等旧推断须以当前工具及后续固件证据为准。
不能凭片段编号判断它是否相机原生录制。

## 文件安全

卡接回电脑后先确认盘符、做新快照，再分析或写入。
新片段编号必须从当前文件、DATABASE和MEDIAPRO共同检查，示例编号不保留。
历史快照只能提供经依赖核验的模板，不能整库回写。
普通部署不覆盖已有片段；定点修正需要单独授权。未经明确许可不删除卡文件。
旧验证报告、原始媒体和原始实机反馈不追改为新的结果。
